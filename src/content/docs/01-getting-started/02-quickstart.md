# Quickstart Guide

Get up and running with your first Vinum project in under 2 minutes.

## 1. Create a Project
Click **New Project** in the project dashboard, enter a project name, and hit create.

## 2. Edit & Preview
Write Vinum syntax on the left. The live preview updates automatically on the right with debounced compilation.
